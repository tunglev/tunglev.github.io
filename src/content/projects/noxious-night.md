Noxious Night was our entry for **GMTK GameJam 2023**. It's a horror game following Stevenson, an eight-year-old boy, through a dark and twisted journey. The theme was "Roles Reversed."

### Theme Implementation

We took the trope of an innocent old grandma and reversed it. Normally a grandma's role is to protect, spoil, and love their grandkids — but in this game, she does not. The result is a tense, atmospheric horror experience.

### Technical Contributions

- **Custom Path Editor** — Programmed an easy-to-use and scalable path editor for level design, making it simple for other team members to create and modify paths.
- **Custom Ray-Casting AI** — Implemented AI, movement, and collision for the Granny enemy using custom ray-casting logic, reducing visual detection errors by over 50%.
- **Version Control** — Used GitHub with optimized pull requests and code reviews to coordinate work between 3 programmers, reducing merge conflicts by 32%.

### Design Philosophy

I focused on avoiding premature optimization — we prioritized shipping a working game over perfect code. The result was a complete, polished game jam entry that told a compelling story.

### Technologies

Unity, C#, WebGL, Custom AI

### Platforms

Available on **Windows** and **Itch.io**.
