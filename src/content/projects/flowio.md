FlowIO is a comprehensive AI-powered desktop application I built to streamline the job hunting process for developers and job seekers. It combines intelligent automation with an intuitive interface to transform how professionals manage their job applications.

### What It Does

- **One-click Data Extraction** — Automatically extracts job posting details from any source.
- **Resume-to-Job Matching** — AI-powered matching between resumes and job requirements.
- **Intelligent Email Generation** — Auto-generates personalized outreach emails.
- **Offline-First with Cloud Sync** — Full offline functionality with Firebase cloud backup.

### Key Technologies

**Frontend:** React 18+, TypeScript, Vite, Radix UI, TailwindCSS, TanStack React Table
**Backend:** Node.js/Express.js, Firebase Admin SDK, Firebase Storage
**AI:** Google Gemini AI API for NLP, job parsing, resume matching, and email generation
**Desktop:** Electron Framework (cross-platform), Electron Builder for packaging

### Notable Achievements

- Successfully migrated from local storage to cloud-based Firebase infrastructure
- Integrated Google Gemini AI for intelligent job parsing and matching
- Built cross-platform desktop support (Windows, Mac, Linux)
