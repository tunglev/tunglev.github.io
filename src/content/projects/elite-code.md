Elite Code is a gamified microlearning platform designed to help users prepare for technical interviews in a fast, fun, and effective way. The tagline: "The Fast, Fun Way to Nail Interviews with Gamified Microlearning."

### My Contribution

I worked on this project during my time at **BUILD**, contributing to both the UI/UX design (using Figma) and frontend coding.

### Features

- Gamified microlearning approach to interview preparation
- Bite-sized coding challenges designed for retention
- Engaging UI to make studying feel less like a chore

### Technologies

HTML, CSS, JavaScript, Figma (UI/UX design)
